## 📱 Mobile Installation (PWA)

### Android (Chrome)
1. Open the GitHub Pages URL in Google Chrome.
2. Tap the **"Install App"** button in the header or Chrome's three dots `⋮` $\rightarrow$ **"Install App"** / **"Add to Home screen"**.
3. It installs as a native WebAPK with full offline capabilities!
4. **Android Native Share Target**: When browsing products in Amazon, Flipkart, or Myntra, tap **Share** $\rightarrow$ select **"YOU DON'T NEED IT"**. The app automatically extracts the link, identifies the product, and launches interrogation!

### iPhone (iOS Safari)
1. Open the GitHub Pages URL in Safari.
2. Tap the **Share button** (`[↑]`) at the bottom of the screen.
3. Scroll down and tap **"Add to Home Screen"** (`[+]`).
4. The app launches fullscreen in standalone app mode without Safari browser toolbars!
5. **Sharing links on iOS**:
   - **Auto-Clipboard**: Copy any link from Amazon/Flipkart. Opening this app automatically detects the shopping link on your clipboard.
   - **iOS Shortcut**: Create a 2-step Apple Shortcut (Receive Share Sheet input $\rightarrow$ Open `https://georgepoyilil.github.io/doNotBuyIt-overkillVersion/?url=ShortcutInput`) to enable 1-tap sharing directly from iOS Share Sheet.

## 🚀 GitHub Pages Setup

1. In your GitHub repository: Go to **Settings** $\rightarrow$ **Pages**.
2. Under **Build and deployment** $\rightarrow$ **Source**, select **Deploy from a branch**.
3. Choose branch **`main`** and folder **`/(root)`**, then click **Save**.
4. In ~60 seconds, your PWA is live at `https://georgepoyilil.github.io/doNotBuyIt-overkillVersion/`!
